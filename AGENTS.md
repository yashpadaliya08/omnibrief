# Permanent Documentation & Knowledge Standard

Every project must maintain a dedicated, production-grade `docs/` folder containing:
1. `docs/REQUIREMENTS.md`: Criteria, hackathon rules, sponsor constraints, compliance checklist.
2. `docs/PROBLEM_AND_SOLUTION.md`: Real-world pain points, architecture narrative, and model rationale.
3. `docs/ARCHITECTURE_GUIDE.md`: Deep technical guide, directory map, data models, sequence flows, and APIs.
4. `docs/PROGRESS_AND_ROADMAP.md`: Active milestone tracker, changelog, and upcoming roadmap items.
5. `docs/SUBMISSION_PITCH_GUIDE.md`: Copy-paste ready submission answers, 3-minute video demo script, and judging criteria mapping.

Keep documentation synchronized proactively with all code changes across all sessions.
